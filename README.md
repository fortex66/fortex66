## 🚀 What I Build

### AI 기반 현장 모니터링 시스템

LabVIEW 기반 현장 모니터링 프로그램과 Python AI 서비스를 연결하여 음성 또는 자연어를 통해 설비 정보를 조회하고, 구조화된 명령을 전달할 수 있는 시스템을 개발하고 있습니다.

```text
Operator
   ↓
Voice / Natural Language
   ↓
Local LLM · AI Tool
   ↓
Python HTTP Interface
   ↓
LabVIEW Monitoring System
   ↓
Equipment Data & Control
```

### Industrial Robot Program Viewer

메모장이나 전용 프로그램에 의존하던 산업용 로봇 프로그램을 더욱 쉽게 분석할 수 있도록 프로그램 분기, 호출 관계, 명령어 및 로봇 이동 경로를 시각화하는 전용 IDE를 개발하고 있습니다.

### Manufacturing Process Intelligence

설비 데이터를 단순히 저장하는 것을 넘어 공정 상태를 분석하고, 이상 원인과 작업자의 의사결정을 지원할 수 있는 제조 데이터 활용 구조를 연구하고 있습니다.

### Closed-loop Process Control

작업자의 수동 조정에 의존하던 공정을 센서 데이터와 제어 변수를 활용한 폐루프 제어 구조로 전환하여 공정 재현성과 품질 안정성을 높이는 기술을 개발하고 있습니다.

## 💡 Engineering Principles

> **현장을 이해하지 못한 AI는 제조 현장의 문제를 해결할 수 없습니다.**

제가 중요하게 생각하는 것은 새로운 기술 자체가 아니라, 기술이 현장의 문제를 실제로 해결할 수 있는지입니다.

* 현장과 공정을 먼저 이해합니다.
* 제어 시스템의 안정성을 우선합니다.
* 복잡한 프로그램을 읽기 쉬운 구조로 만듭니다.
* 반복 작업은 자동화하고 판단이 필요한 일에 집중합니다.
* AI를 독립된 기능이 아닌 기존 시스템을 강화하는 도구로 활용합니다.
